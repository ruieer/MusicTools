## Что нового в 1.0.0

- Скачивание музыки с YouTube и SoundCloud: M4A или MP3, битрейт 128 / 192 / 256 кбит/с.
- Теги и обложки из MusicBrainz, Spotify, Deezer, Bandcamp и Last.fm, ручной разбор неподходящих
  треков, проверка громкости, ремонт обложек и переименование файлов по шаблону.
- Передача на iPod nano 2G без iTunes и без iTunes API: треки, `iTunesDB`, `ArtworkDB`, плейлисты,
  резервная копия базы перед каждой записью.
- Библиотека iPod: список треков, поиск, сортировка, правка тегов прямо в базе, удаление треков.
- Интерфейс с переключателем языка (русский и английский); в свежей установке включён английский,
  «Авто» берёт язык Windows.
- Обновление инструментов без пересборки: Настройки → «Обновить инструменты» скачивает свежие
  yt-dlp и ffmpeg в папку `tools` рядом с exe, они перекрывают встроенные.
- Сборка на ffmpeg и ffprobe 9.1.

## Установка

Скачайте `MusicTools.exe` ниже. Файл самодостаточный: Python, yt-dlp, ffmpeg и ffprobe уже внутри,
доустанавливать ничего не нужно — положите его в отдельную папку и запустите.

- Windows 10/11, 64 бита, права администратора не нужны.
- Рядом с exe создаются `config.json`, `report.csv`, `meta_cache.json`, логи и папка `music`.
- При первом запуске exe распаковывает встроенные ffmpeg/ffprobe во временную папку, поэтому старт
  занимает несколько секунд.

## Заметки

- Описание и документация проекта — на русском языке. **Только на русском языке!** / **In Russian
  only!**
- yt-dlp быстро устаревает из-за изменений на YouTube: `pip install -U yt-dlp`.
- Ключи Spotify и Last.fm хранятся в `config.json` открытым текстом; они не обязательны.
