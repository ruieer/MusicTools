## What's new in 1.0.1

- **English translation of the interface.** The whole app now speaks English: the sidebar, every page and its hints, buttons, dialogs, confirmations and the whole engine log (download, tags, covers, volume, manual review, iPod transfer and library editing).
- **Language selector:** Settings → *Interface language* with `English`, `Русский` and `Auto`. The choice is stored in `config.json` as `"language"`; switching it saves the settings and restarts the app so every label is rebuilt in the chosen language.
- **English is the default** for a fresh install. `Auto` follows the Windows UI language — Russian Windows gives Russian, anything else gives English.
- The answer buttons under the prompt line work in both languages: they recognise the Russian prompt or its English translation.

## Install

Download `MusicTools.exe` below. It is self-contained — Python, yt-dlp, ffmpeg and ffprobe are bundled, nothing else to install.

## Notes

- `docs/ipodnano2g.md` is still in Russian; code comments stay in Russian as well.
- Everything else behaves as in 1.0.0: YouTube/SoundCloud downloads, MusicBrainz/Spotify/Deezer/Bandcamp/Last.fm tags and artwork, iTunes-free sync to an iPod nano 2G.
