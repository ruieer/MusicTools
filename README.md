# Music Tools

Windows-GUI для закидывания музыки на iPod: скачивание с YouTube/SoundCloud, правка тегов и
обложек, ручной разбор неподходящих треков, проверка громкости, ремонт обложек и передача всего
этого на подключённый iPod.

> **Только на русском языке!** Описание, документация и общение по проекту — на русском.
> **In Russian only!**

## Скачивание

Готовый `MusicTools.exe` лежит в разделе **Releases** этого репозитория. Он самодостаточный: Python,
yt-dlp, ffmpeg и ffprobe уже внутри, доустанавливать ничего не нужно. Скачайте один файл, положите
его в отдельную папку и запустите.

- Windows 10/11, 64 бита. Права администратора не нужны.
- Рядом с exe создаются `config.json`, `report.csv`, `meta_cache.json`, логи и папка `music`. Эта
  папка — всё, что нужно сохранять.
- При первом запуске exe распаковывает встроенные ffmpeg/ffprobe во временную папку, поэтому
  старт занимает несколько секунд.
- Интернет нужен только для скачивания музыки и поиска обложек.

Exe весит больше 100 МБ, поэтому в репозитории его нет — он публикуется как файл релиза.

## Сборка exe

Нужны Python 3.10+ и ffmpeg с ffprobe в `bin\`.

    pip install -r requirements.txt pyinstaller
    python -m PyInstaller --noconfirm --clean MusicTools.spec

На выходе получается `dist\MusicTools.exe`. Сборка на GitHub (Actions → **Build exe** → Run
workflow) делает то же самое: скачивает ffmpeg, собирает exe и прикладывает его к артефактам
workflow; для тега вроде `v1.0.0` она создаёт релиз с этим файлом.

## Передача на iPod

Страница «iPod» пишет треки и `iTunesDB` сама, без запуска iTunes и без iTunes API. Проверенная
модель — iPod nano 2G.

- Устройство ищется по папке `iPod_Control` (буква диска не важна); если подключено несколько
  iPod, нужный выбирается из списка.
- Если модель определить не удалось, нужно подтвердить, что это nano 2G. Остальные модели,
  которые поддерживает pygpod (1G–5G, mini, nano 1G/3G/4G, video, classic), доступны только за
  галочкой «экспериментально». Shuffle и nano 5G+ (база SQLite) не поддерживаются.
- FLAC, Ogg, Opus и WMA конвертируются в AAC 256k (кэш в `ipod_convert_cache`); теги и обложки
  берутся из исходного файла.
- Дубликаты (по SHA-256) не копируются; треки можно сразу добавить в плейлист.
- Обложки из тегов пишутся в `ArtworkDB` (это можно отключить).
- Перед любым изменением делается датированная копия `iTunesDB`, `ArtworkDB`, файлов `.ithmb` и
  настроек в `iPod_Control\iTunes\MusicToolsBackups`. После записи база читается заново; если новых
  записей в ней нет, она восстанавливается из копии, а скопированные файлы удаляются.
- iTunes должен быть закрыт (`iTunesHelper` может запустить его сам — программа предупредит).
  После передачи iPod можно извлечь кнопкой «Извлечь iPod».

Запись базы выполняется через pygpod (LGPL-2.1-or-later): https://github.com/Bionded/pygpod.

## Библиотека iPod

Вкладка «Библиотека iPod» показывает треки на устройстве (поиск, сортировка по столбцу). Можно
менять название, исполнителя, альбом, исполнителя альбома, жанр, год и номер трека — для одного
трека или сразу для нескольких (пишутся только изменённые поля) — и удалять выбранные треки вместе
с файлами. Теги меняются только в `iTunesDB`; сами аудиофайлы не перезаписываются. Перед каждой
записью делается копия базы; удалённые аудиофайлы в неё не входят.

## Запуск из исходников

    pip install -r requirements.txt
    python src/app.py

ffmpeg и ffprobe должны быть в `PATH` или в папке `bin\`.

Формат скачивания (M4A или MP3) и битрейт (128 / 192 / 256 кбит/с) выбираются в настройках.
YouTube обычно отдаёт AAC около 128 кбит/с; более высокое качество и MP3 получаются
перекодированием.

`config.json`, `report.csv`, `meta_cache.json`, логи и папка `music` по умолчанию создаются рядом
с программой.

## Структура

- `requirements.txt` — зависимости.
- `bin/` — ffmpeg и ffprobe.
- `src/` — исходный код: `app.py` (окно), `ui/pages.py` (страницы инструментов), `core/` (пути,
  настройки, фоновый запуск), `engine/` (скрипты скачивания и тегирования).
- `docs/` — заметки про iPod nano 2G.
- `backup/` — старые копии файлов для справки (создаётся локально, в репозиторий не попадает).
- `ipod_convert_cache/` — кэш конвертации для iPod (создаётся при работе).

## Заметки

- Инструменты можно обновить прямо из программы: Настройки → «Обновить инструменты». Свежие
  yt-dlp и ffmpeg скачиваются в папку `tools` рядом с exe и перекрывают встроенные — пересобирать
  exe не нужно.
- yt-dlp быстро устаревает из-за изменений на YouTube: `pip install -U yt-dlp`.
- Ключи Spotify и Last.fm хранятся в `config.json` открытым текстом. Они не обязательны; ключ
  Last.fm можно также передать через переменную окружения `LASTFM_API_KEY`.
