# Сторонние компоненты

Собранный `MusicTools.exe` включает перечисленные компоненты; исходники и лицензии — по ссылкам.

| Компонент | Назначение | Лицензия |
|---|---|---|
| [ffmpeg / ffprobe](https://www.gyan.dev/ffmpeg/builds/) | перекодировка, громкость, обложки | GPL v3 (сборка essentials) |
| [yt-dlp](https://github.com/yt-dlp/yt-dlp) | скачивание с YouTube и SoundCloud | Unlicense |
| [pygpod](https://github.com/Bionded/pygpod) | чтение и запись базы iPod | LGPL-2.1-or-later |
| [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter) | интерфейс | MIT |
| [mutagen](https://mutagen.readthedocs.io/) | теги и обложки | GPL-2.0-or-later |
| [Pillow](https://python-pillow.org/) | обработка изображений | HPND |
| [requests](https://requests.readthedocs.io/) | HTTP | Apache-2.0 |
| [rapidfuzz](https://github.com/rapidfuzz/RapidFuzz) | нечёткое сравнение названий | MIT |

ffmpeg распространяется отдельным бинарником: исходный код — https://ffmpeg.org/download.html.
